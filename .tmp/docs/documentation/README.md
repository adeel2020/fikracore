## 🛠 Adding Documentation Guidelines
When updating system features or introducing new agent crew skills, please capture modifications using the **Low-Level Design (LLD)** format. 

### LLD Requirements
1. **Component Scope & Objective:** Outline why the component is introduced and who it serves.
2. **Ontology & Schema Modifications:** Detail any database table updates or JSON graph node schemas.
3. **Data Flows:** Use Mermaid flow diagrams to visualize inter-system signals.
4. **Performance & Optimization:** Document physics adjustments, lazy-loading thresholds, or memoization tricks.
