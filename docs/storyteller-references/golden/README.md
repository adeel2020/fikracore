# Golden Storyteller References

These files are deterministic regression references for the professional
storyteller contract. They are built from hermetic test context, not live
gbrain data, so they can run in CI and catch quality regressions.

The live `docs/storyteller-references/<incident>/<timestamp>/` bundles remain
useful for manual review. This `golden/` folder is stricter: it pins stable
written output, spoken output, and visual contract expectations.
