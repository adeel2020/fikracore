# Stakeholder Update

Use this skill when Mark needs to prepare an email, WhatsApp update, Microsoft Teams update, shift handover note, customer update, or management summary.

Draft first. Do not send without explicit approval.

Translate technical context into the audience's language. For executives, summarize service impact, severity, business risk, current confidence, and next action. For NOC or engineering teams, include affected components, evidence, timestamps, owner, and requested action.

Use FCAPS to make sure the update does not omit relevant fault, change request, performance, accounting, or security context when that evidence exists.
